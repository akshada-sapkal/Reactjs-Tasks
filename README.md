# 🚀 Included Project

## 🎓 Student Form Application

A responsive student registration form built using React JS.

### Features
- Add student details
- Gender selection using radio buttons
- Skills selection using checkboxes
- Dynamic state dropdown
- Form submission handling
- Success message display
- Form reset functionality
- Responsive UI
