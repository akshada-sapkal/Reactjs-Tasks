# 🚀 Included Project

## 🎓 Student Form Application

A responsive student registration form built using React JS.

### Features
- Add student details
- Gender selection using radio buttons
- Skills selection using checkboxes
- Dynamic state dropdown
- Form submission handling
- Success message display
- Form reset functionality
- Responsive UI

# ▶️ Run the Project

## 1️⃣ Clone Repository

```bash
git clone <your-repository-link>
```

## 2️⃣ Install Dependencies

```bash
npm install
```

## 3️⃣ Start Development Server

```bash
npm run dev
```

## 4️⃣ Open Browser

```bash
http://localhost:5173
```
